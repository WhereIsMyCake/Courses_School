    历年卷参考¶

    第一份¶

    名词解释（5*7=35）¶

    1. 地形图（Topographic Map）
      地形图是普通地图的一种，以详细表示地面上各种地形（如地貌、水系、植被等）和地物（如居民地、道路、境界等）的平面位置和高程为核心，通过数学基础（投影、坐标）、地理要素（自然与社会经济要素）和辅助要素（图廓、图名等）协同，反映地表自然地理与社会经济要素的分布、特征及相互关系，是地图学中用于地理认知与空间分析的基础地图类型。

    2. 大地水准面（Geoid）
      大地水准面是平均海平面延伸至大陆内部形成的闭合曲面，作为地球形状的近似参考面，其起伏反映了地球内部质量分布的不均匀性。它是地理坐标系（如大地坐标系）的高程基准面，为地图投影、坐标系统建立提供几何基础，确保地理信息的空间准确性。

    3. 网络地图服务（Web Map Service, WMS）
      WMS是Open Geospatial Consortium (OGC)定义的网络制图核心服务，允许客户端通过请求获取地图图像。其特点包括动态绘制地图（反映数据最新状态）、支持交互操作（如查询、图层切换），适用于网络地图的实时更新与多用户访问，是Web Mapping的技术基础之一。

    4. 多变量地图（Multivariate Map）
      多变量地图是表示多个相关变量（属性）的专题地图，如双变量地图通过整合符号（可分符号、整合符号）或可视化方式（如分级统计图、点值图），展示变量间的空间关系（如相关性）。它能突破单变量地图的信息局限，揭示复杂地理现象的内在联系。

    5. 通用横轴墨卡托（Universal Transverse Mercator, UTM）
      UTM是一种等角圆柱投影，将地球划分为60个6°经度带，每个带独立投影。其特点是保持等角性质，适用于大范围地图（如军事、工程），通过横轴墨卡托投影实现地球曲面到平面的转换，确保方向与形状的局部准确性。

    6. HSV
      HSV是色彩模型，包含色相（Hue，颜色种类）、饱和度（Saturation，颜色纯度）、明度（Value，颜色明暗）。在地图色彩设计中，HSV用于控制色彩的视觉属性（如区分要素类别、强调等级），是地图符号化的重要工具。

    7. 制图综合（Map Generalization）
      制图综合是根据地图用途、比例尺、制图区域特点，对制图物体进行选取（选重要物体）、概括（化简形状/数量/质量特征）、处理空间关系的过程。其目的是解决“地图详细性与易读性”的矛盾，突出地理现象的规律性，是地图制作的核心创造性环节。

    简答（50）¶

    1. 数学方法在绘制地图中的运用
      数学方法是地图学的技术基础，核心包括：

      • 地图投影：将地球曲面转换为平面（如墨卡托投影、UTM投影），确保地理要素的空间准确性；
      • 坐标系统：建立大地坐标系（如CGCS2000）或平面直角坐标系，实现地理定位；
      • 比例尺：通过代表分数、文字说明或比例条，表示地图缩放关系；
      • 几何变换：如缩放、旋转，调整地图要素的视觉表达。
        这些方法确保地图的数学精度，使地理信息能被准确传输与解读。

    2. 地图的要素及其作用
      地图要素是地图传输地理信息的基本单元，包括：

      • 图廓线与内图廓线：组织内容、定义地图范围；
      • 制图区域：含专题符号（主题要素）与基础信息（地理参考框架），是地图的核心表达区；
      • 插图：补充主图（如定位图、放大图），增强空间理解；
      • 标题与副标题：说明地图主题（如“中国人口密度图”）；
      • 图例：定义符号含义，确保可读性；
      • 数据源：说明数据来源，保证可信度；
      • 比例尺：表示缩放关系，支持距离测量；
      • 方向：指示北向（如指北针、格网）。
        作用是通过要素协同，实现地理信息的“可读性”与“可翻译性”，传递空间规律。

    3. 地图的度量水平（Measurement Level）及适用于度量水平的视觉要素
      度量水平分为四类，对应视觉要素：

      • 定名（Nominal）：区分类别（如“城市”“乡村”），用色相（不同颜色）表示；
      • 有序（Ordinal）：表示等级（如“一级公路”“二级公路”），用明度（深浅）表示；
      • 间隔（Interval）：表示有间隔但无绝对零点的数据（如温度），用饱和度（纯度）表示；
      • 比率（Ratio）：表示有绝对零点的数据（如人口密度），用大小（符号尺寸）表示。

      • 新中国史上使用的大地坐标系统及其特点
        新中国大地坐标系统经历了从“参心”到“地心”的演进：

      • 1954年北京坐标系：基于苏联克拉索夫斯基椭球，属参心坐标系，精度有限；

      • 1980年西安坐标系：基于IAG75椭球，属参心坐标系，精度提升；
      • 2000国家大地坐标系（CGCS2000）：基于ITRF97，属地心坐标系，精度高且与WGS84兼容。
        特点：随测绘技术发展，精度逐步提升，坐标系类型从参心转向地心，适应全球地理信息共享需求。

    4. 地图投影选择

      • a.中国人口点密度图：需保持面积比例，选择等积投影（如Albers投影）；
      • b.世界航海图：需等角（利于航行方向判断），选择墨卡托投影；
      • c.中国东南沿海台风路径图：需等角或等距（准确表示路径方向），选择UTM投影或墨卡托投影。

    5. 等值区域图的缺点及技术解决
      缺点：①视觉误导（大区域吸引注意力，忽略区域内数据不均匀）；②地理适应性差（无法反映区域内差异）。
      技术手段：①Dasymetric Maps（分区密度图）：结合土地利用数据调整区域边界，增强地理适应性；②Cartogram（地图统计图）：按数据大小调整区域面积，消除面积误导；③Value-by-Alpha（值-alpha图）：用透明度区分区域，减少视觉干扰。

    6. 古代希腊制图成就及对地图学的影响
      成就：①托勒密《地理学指南》（27幅地图，创造球面投影与普通圆锥投影）；②埃拉托色尼测量地球周长；③斯特拉波《地理学》（系统描述地理现象）。
      影响：奠定地图学理论基础（如投影方法、地理认知逻辑），推动“科学制图”发展，为后世地图制作提供方法参考（如坐标系统、符号化）。

    论述（15）¶

    绘制疫情网络地图的数据及方法

    • 数据需求：
      1. 病例数据：确诊、疑似、治愈、死亡病例的地理位置（点数据）；
      2. 人口数据：区域人口密度（用于计算感染率，辅助分析传播风险）；
      3. 交通数据：航班、铁路等流动数据（分析疫情传播路径）；
      4. 医疗资源数据：医院位置、床位数量、核酸检测点（展示资源分布，辅助决策）。
    • 网络地图绘制方法：
      1. 技术框架：采用Web Map Service (WMS) 提供底图（如OpenStreetMap），用Leaflet API 构建交互界面；
      2. 数据存储与可视化：以GeoJSON 存储病例数据，通过符号（不同颜色/大小的点表示病例类型）、热力图（显示感染密度）、时间滑块（展示疫情发展）实现动态可视化；
      3. 交互设计：添加Popup（点击显示病例详情）、图层控制（切换病例类型、医疗资源图层），确保用户可自主探索数据；
      4. 实时更新：通过WMS动态获取最新数据，保证地图信息的时效性。
        该方法结合网络制图技术与专题数据，实现疫情信息的直观、交互式展示，为公众与决策者提供空间决策支持。

    第二份¶

    1. 地图的基本特征和功能¶

    • 基本特征：
      1. 地理信息的载体：地图是地理信息的图形表达，传递空间分布规律；
      2. 数学法则的结构：通过投影、坐标系统实现地球曲面到平面的转换，确保空间准确性；
      3. 有目的的地图概括：根据用途、比例尺简化内容，突出本质特征；
      4. 符号系统的运用：用符号（点、线、面）表示地理要素，实现信息可视化。
    • 功能：
      1. 认知功能：建立空间概念（位置、范围、格局），运用图形思维理解质量/数量特征；
      2. 载负功能：传递直接信息（如水系、居民点）和间接信息（如坡度、经济结构）；
      3. 传递功能：作为信息传输工具，实现跨语言、跨文化的地理信息交流；
      4. 模拟功能：通过物质模型（普通地图）或概念模型（专题地图）抽象地理规律。

    2. 古希腊地图制作的成就¶

    • 核心成就：
      1. 托勒密《地理学指南》：包含27幅地图，创造球面投影（用于全球地图）和普通圆锥投影（用于区域地图），奠定投影理论基础；
      2. 埃拉托色尼：首次测量地球周长（约4万公里，与现代值接近），推动地理定量研究；
      3. 斯特拉波《地理学》：系统描述地理现象（如气候、资源），建立地理认知框架。
    • 影响：奠定地图学“科学制图”基础，推动投影方法、地理认知逻辑的发展，为后世地图制作提供方法参考。

    3. 地图的主要要素(elements)及其作用¶

    • 主要要素：
      1. 图廓线与内图廓线：图廓线包围所有要素，定义地图范围；内图廓线裁切制图区域，避免内容溢出；
      2. 制图区域：含专题符号（主题要素，如人口密度点）和基础信息（地理参考，如道路、水系），是地图核心表达区；
      3. 插图：补充主图（如定位图、放大图），增强空间理解（如台风路径的局部放大）；
      4. 标题与副标题：说明地图主题（如“浙江省24小时人口分布图”），副标题补充地理范围/时间；
      5. 图例：定义符号含义（如点的大小表示人口数量），确保可读性；
      6. 数据源：说明数据来源（如“数据来自浙江省统计局”），保证可信度；
      7. 比例尺：表示缩放关系（如1:100万），支持距离测量；
      8. 方向：指示北向（如指北针、格网），确保空间方向准确。
    • 作用：通过要素协同，实现地理信息的“可读性”与“可翻译性”，传递空间规律。

    4. 地图标注错误（根据提供的地图分析）¶

    • 具体错误：
      1. “Don’s”的箭头指向错误：箭头应指向标注对象（如餐厅位置），但图中箭头方向偏离目标；
      2. “Oceanview Inn”标注位置不当：应紧邻对应符号（橙色点），但图中标注与符号距离过远；
      3. “Crescent Bay”拼写错误：应为“Crescent Bay”（地图中可能误写为“CRESCENT BAY”，需确认拼写一致性）；
      4. 街道名称标注遗漏：“Fisk Loop”未完整标注（如“Loop”部分缺失），导致空间关系不明确。

    5. 数据的四个度量水平及视觉要素¶

    • 度量水平：
      1. 定名（Nominal）：区分类别（如“城市”“乡村”），无顺序；
      2. 有序（Ordinal）：表示等级（如“一级公路”“二级公路”），有顺序但无间隔；
      3. 间隔（Interval）：有间隔但无绝对零点（如温度），可加减；
      4. 比率（Ratio）：有绝对零点（如人口密度），可加减乘除。
    • 视觉要素：
      1. 定名：用色相（不同颜色）区分类别；
      2. 有序：用明度（深浅）表示等级；
      3. 间隔：用饱和度（纯度）表示数据差异；
      4. 比率：用大小（符号尺寸）表示数量。

    6. 大地坐标系统及新中国使用的大地坐标系统¶

    • 大地坐标系统：
      是用于确定地球表面点位置的参考框架，包括大地水准面（高程基准）、椭球体（形状基准）和坐标原点，确保地理定位的准确性。

    • 新中国使用的大地坐标系统：

      1. 1954年北京坐标系：基于苏联克拉索夫斯基椭球，属参心坐标系（原点在苏联），精度有限；
      2. 1980年西安坐标系：基于IAG75椭球，属参心坐标系，精度提升，原点位于中国；
      3. 2000国家大地坐标系（CGCS2000）：基于ITRF97，属地心坐标系，精度高且与WGS84兼容，适应全球地理信息共享。
    • 特点：随测绘技术发展，精度逐步提升，坐标系类型从“参心”转向“地心”，满足现代地理信息需求。

    7. 地图投影选择¶

    • 1) 我国东海的台风路径图：选择墨卡托投影（等角投影），因为台风路径需要准确的方向判断（如路径的弯曲、移动方向），等角投影保持方向不变；
    • 2) 中国人口分布图：选择Albers投影（等积投影），因为人口分布需反映面积比例（如省份人口密度与实际面积的关系），等积投影保持面积不变。

    8. 多变量地图的对比和合并¶

    • 对比（Comparing）：
      通过不同视觉变量（如颜色、符号）展示变量间的差异（如“人口密度”与“GDP”的对比），突出变量间的矛盾或关联，便于用户识别差异；

    • 合并（Combining）：
      整合多个变量（如用符号组合表示“人口密度+GDP”），通过符号的复合（如点的大小+颜色）传递综合信息，减少地图负载，提升信息密度。

    • 特点：对比强调“差异”，合并强调“整合”，两者结合可全面展示复杂地理现象。

    9. 浙江省24小时人口时空分布地图的设计（网络地图三要素）¶

    • 网络地图三要素：底图、专题图层、交互元素。
    • 设计思路：
      1. 底图：选择OpenStreetMap（开源、高精度），提供地理背景（如道路、行政区划）；
      2. 专题图层：
        • 用热力图表示人口密度（颜色深浅对应密度高低，如红色表示高密度）；
        • 添加时间滑块（控制24小时的时间变化，如“8:00”“12:00”），动态展示人口流动；
        • 用点符号（不同大小表示人口数量）标注重点区域（如杭州、宁波）；
      3. 交互元素：
        • Popup：点击区域显示详情（如“杭州市8:00人口密度：5000人/平方公里”）；
        • 图层控制：切换时间（如“早高峰”“晚高峰”）、人口类型（如“常住人口”“流动人口”）；
        • 搜索框：输入区域名称（如“杭州”），快速定位。
    • 目的：通过三要素协同，实现人口时空分布的直观、交互式展示，为城市规划、交通管理提供决策支持。
